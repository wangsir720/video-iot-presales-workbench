# TCO 对比 · 某制造园区周界防入侵与安全生产监测

## 一、基准方案（本方案）

| 项目 | 金额（元） | 说明 |
|---|---:|---|
| 硬件设备 | 93530.0 | 前端 + 存储 + 网络 + 算力 + 平台 |
| 施工安装 | 14029.5 | 按硬件金额 15% 计取 |
| 3 年运维 | 22447.2 | 按硬件金额 8%/年计取 |
| **合计** | **130006.7** | 公开参考价口径 |

## 二、对比口径

| 维度 | 基准方案 | 说明 |
|---|---|---|
| 前端路数 | 16 路 | 一致 |
| 存储天数 | 30 天 | 一致 |
| 智能能力 | 前端 + 边缘双重研判 | 基准含边缘盒子，替代方案若改为纯平台分析会占用服务器算力 |
| 平台授权 | 按路数授权 | 后期扩容按每 100 路扩容 |

## 三、决策建议

- 若客户预算受限，可优先保留**存储与前端**，把边缘算力改为分期建设。
- 若客户端强调**降低误报**，建议保留边缘侧二次研判，其价值在于减少无效出警而非节省硬件。
- 若项目后续要扩容，平台建议一次性按上限授权，避免二次采购的差价。

> 全部金额均为公开渠道档位参考值，正式报价以厂商报价单为准。
